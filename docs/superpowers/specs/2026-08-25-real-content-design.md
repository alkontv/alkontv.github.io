## 1. Контекст

Фаза 1 закрыта: форк `mohitvirli.github.io` вычищен, введён самописный i18n,
работает переключатель RU/EN, сайт задеплоен на GitHub Pages и отвечает по
`https://alkontv.github.io`.

При этом **весь контент сайта выдуман**. В `constants/projects.ts` шесть
несуществующих проектов, у каждого ссылка ведёт на пустой профиль GitHub;
в `constants/work.ts` таймлайн-плейсхолдер; в `public/Alan-CV-{ru,en}.pdf`
резюме с теми же выдуманными кейсами.

Это активный вред, а не незавершённость: клиент, открывший карточку и нажавший
VIEW, обнаруживает, что показывать нечего. Резюме с несуществующими проектами —
прямой риск на собеседовании.

Одновременно в хранилище задокументирован реальный трек-рекорд: **2 234 980 ₽
на 18 оплаченных проектах** с 7 апреля 2023, 52 репозитория на GitHub, менторство пятерых
учеников. Задача — перенести эту фактуру в три формата, которыми пользуются
клиенты.

## 2. Цель

К концу работ у Алана есть три согласованных между собой артефакта на двух
языках, собранных из одного источника контента:

1. **3D-сайт** — витрина-«вау» с шестью сильнейшими кейсами.
2. **Страница `/cases`** — быстрая, читаемая, её не стыдно кинуть ссылкой в чат.
3. **PDF-презентация** — для лички, откликов и вложений.

Плюс переписанное на реальных фактах резюме.

## 5. Архитектура контента

Единый источник правды в репозитории портфолио. Правка текста в одном месте
расходится во все три формата.

```
app/content/
  types.ts          // CaseStudy, CaseFormat, Stats, LocalizedText
  stats.ts          // сводные цифры
  timeline.ts       // реальный таймлайн (заменяет constants/work.ts)
  cases/
    index.ts        // export const CASES: CaseStudy[]
    safety.ts
    creator-app.ts
    ...             // по файлу на кейс, 14 штук
```

### 5.1 Модель кейса

```ts
export type CaseFormat =
  | 'mobile' | 'web' | 'telegram' | 'backend' | 'ai' | 'admin' | 'payments';

export interface CaseStudy {
  id: string;                  // 'safety' — якорь на /cases и в ссылке из 3D
  industry: LocalizedText;     // «Личная безопасность»
  formats: CaseFormat[];       // чем закрыт кейс — для фильтра и иконок
  name: LocalizedText;         // обезличенное имя-описание
  budget?: number;             // ₽; отсутствует у своих продуктов
  status: 'shipped' | 'production' | 'beta' | 'active' | 'mvp';
  tagline: LocalizedText;      // одна строка — для 3D-плитки
  problem: LocalizedText;      // что просил заказчик
  solution: LocalizedText[];   // 3–5 буллетов: что сделано
  highlight: LocalizedText;    // инженерная соль кейса
  stack: string[];             // языконезависимо
  integrations: string[];      // платёжки, POS, карты, AI-провайдеры
  scale?: { loc?: number; files?: number };
  diagram?: DiagramId;
  featured: boolean;           // попадает в 3D-карусель
}
```

`LocalizedText` уже есть в `app/i18n/types.ts` — переиспользуем, второй механизм
локализации не заводим.

### 5.2 Как из модели получаются три вывода

- **3D-карусель** — `constants/projects.ts` перестаёт быть источником данных
  и становится проекцией: `CASES.filter(c => c.featured)`, из каждого кейса
  берутся `name`, `status`, `tagline`. Тип `Project` остаётся ради
  `ProjectTile.tsx`, чтобы не переписывать 3D-компоненты.
- **`/cases`** — читает `CASES` целиком.
- **PDF** — генерируется навыком `pdf` из тех же данных; регенерация ручная.
- **Резюме** — берёт `STATS`, `TIMELINE` и шесть featured-кейсов.

### 6.1 Правило дат

Периоды в кейсах не показываются. Даты из git недостоверны: большинство
репозиториев заведены одним заходом в июне 2026 при переносе проектов в git,
поэтому первый коммит датирует импорт, а не разработку. Настоящая история
коммитов есть только у трёх проектов из четырнадцати.

Вместо периода в плитке 3D и в карточке `/cases` показывается **статус**
(«сдан», «в проде», «в работе», «бета», «MVP») — он взят из карточек хранилища
и проверяем.

### 6.2 Гонораров в портфолио нет

Изначально суммы планировалось показывать: это доход Алана, а не тайна
заказчика. Решение **отменено** — оно вредит продаже.

Клиент, увидевший «37 700 ₽» рядом с кейсом, получает якорь на прайс и
дальше торгуется от него. Портфолио отвечает на вопрос «справится ли он
с моей задачей», а не «сколько ему платили»; второе интересно только
самому исполнителю.

По той же причине из шапки убраны число репозиториев и учеников: это
метрики для отчёта, покупателю они ничего не сообщают.

Вместо них — то, что помогает решить, звонить или нет: объём написанного
(40+ приложений и сервисов), число кейсов на странице, охват рынков
(Россия, ОАЭ, Азербайджан, Юго-Восточная Азия) и стаж коммерческой
разработки с 2023 года.

Побочный эффект: спор о точности сводной суммы стал беспредметным.
Независимый пересчёт лога платежей показал, что заявленные 2 234 980 ₽
занижены — подзаголовки разделов не обновляли при добавлении проектов,
и по строкам выходит 3 227 030 ₽ на 21 заказе. Расчёт сохранён
в комментарии `app/content/stats.ts` на случай, если цифра понадобится
в переговорах или резюме — но на витрину она не идёт.

### 6.3 Правило честности формулировок

Ни один кейс не описывается как более готовый, чем он есть. Статус берётся
из карточки хранилища и отражается в тексте:

- «в проде», «сдан» — только там, где так записано;
- «в работе» — для активной разработки;
- кейс 14 описывается через то, что реально сделано, без обещания игры.

## 7. Страница `/cases`

Обычный статический маршрут Next.js, `output: 'export'` его поддерживает.
Без three.js, без GSAP — открывается на слабом телефоне.

Структура:

1. **Шапка** — лид, цифры (2 234 980 ₽ · 18 оплаченных проектов · 52 репозитория
   · с апреля 2023), кнопка в Telegram.
2. **Фильтр по формату** — «всё / мобильные / веб / Telegram / бэкенд / AI».
   Клиентский, без роутинга: показывает, что человек закрывает не только мобилки.
3. **14 карточек** — отрасль, статус, сумма; задача → что сделано →
   инженерная соль; стек и интеграции чипами. Якорь `#<id>` для ссылки из 3D.
4. **Четыре диаграммы** — врезками в соответствующие карточки.
5. **«Что умею»** — по категориям: маркетплейсы с деньгами, платежи, AI
   в продукте, бэкенд и инфраструктура, карты и гео, Telegram, админки.
6. **Подвал** — Telegram, GitHub, резюме по языку, PDF-презентация.

Ссылка VIEW в 3D-плитке ведёт на `/cases#<id>` вместо нынешнего пустого GitHub.

## 8. Диаграммы

Inline-SVG, без библиотек, с токенами темы — работают в светлой и тёмной.
Рисуем только то, что построено; ничего не додумываем.

1. **SOS-сценарий** — нажатие → параллельно: обращение в 112, SMS доверенным,
   запись видео в Storage, событие в базу. Рядом — контур self-hosted Supabase.
2. **Эскроу** — заказчик платит → холд на площадке → работа принята → выплата
   исполнителю, комиссия площадки.
3. **VPN-сервис** — бот и мини-апп → биллинг → провижининг через Go-агента
   на ноду → subscription-ссылка клиенту.
4. **AI как форма ввода** — диалог → структурированная запись → векторный
   подбор → чат.

## 10. Язык по умолчанию

Сейчас дефолт жёстко `en`. Каналов три, языка два — определяем по
`navigator.language` при первом визите, дальше уважаем выбор пользователя
из `langStore` (persist уже реализован).

Реализация: `langStore` получает флаг «язык выбран пользователем». Пока флаг
не поднят, начальное значение берётся из языка браузера (`ru` при `ru-*`,
иначе `en`). Первое нажатие переключателя поднимает флаг навсегда.

## 12. PDF-презентация кейсов

он ведёт на страницу, откуда доступны и презентация, и резюме; это на один
клик длиннее, но не заставляет скачивать файл вслепую.

## 14. Вне рамок

- **Фазы 2–4 предыдущей спеки** (утечки таймеров, производительность 3D,
  доступность) — не мешают получать заказы, откладываются. Исключение:
  проверяем, что сайт открывается и не падает на мобильном.
- **Скриншоты и демо** — невозможны при обезличивании.
- **Google Analytics** — нужен `NEXT_PUBLIC_GA_ID` от Алана; без него тег
  не рендерится, как и сейчас.
- **Кастомный домен** — секрет `GH_PAGES_CUSTOM_DOMAIN` не задан, остаётся
  на `alkontv.github.io`.
- **Кейс Лото** — появится, когда будет код.
- **Сервис для аптек** — появится, когда Алан вспомнит детали.

## 15. Риски

- **Обезличивание стоит доверия.** Клиент не может проверить ни один кейс.
  Компенсируем инженерной конкретикой и цифрами, но размен реален. Путь назад
  открыт: получить у заказчиков разрешение называть — и раскрывать точечно,
  правкой одного поля в карточке кейса.
- **Узнаваемость по связке.** «Маркетплейс подработок с эскроу, в проде» человек
  из рынка опознает. Полной анонимности не будет, только отсутствие прямых имён.
- **Претензия на сторы** (§4) требует подтверждения Алана.
- **Расхождение в хранилище:** по маркетплейсу зооуслуг «Карьера» пишет
  «заказчик перестал доплачивать», «Ситуация сейчас» — «получены полностью».
  На этот отбор не влияет (кейс исключён), но фактуру стоит свести.

- В `constants/projects.ts` и `constants/work.ts` нет ни одного выдуманного
  факта; `grep` по «Flutter Marketplace», «Business CRM», «Analytics Landing» — пусто.

- `/cases` открывается, фильтр работает, якоря из 3D ведут в нужную карточку.
- Оба PDF-резюме и обе PDF-презентации лежат в `public/` и открываются.
- OG-картинка отдаётся, ссылка разворачивается превью.
- Язык определяется по браузеру, выбор пользователя переживает перезагрузку.
- `npm run build`, `npm test` и линт зелёные; `out/` генерируется.
- Сайт и `/cases` проверены на мобильном разрешении.
